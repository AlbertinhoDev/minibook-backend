**2. Server PostgreSQL**
  Via terminal:
  - _2.1 Install PostgreSQL: brew install postgresql_
  - _2.2 Check status PostgreSQL: brew services list_
  - _2.3 If status false, launch PostgreSQL: brew services start postgresql_
  - _2.4 Connect to PostgreSQL: psql -U postgres_


**3. Launch server**
- _go run main.go_
